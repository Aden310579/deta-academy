# Deta Academy

Sekolah trading dari nol sampai bisa, bagian dari DETA Expert.com.

- Cabang `main`: website statis (index.html + brand/). Di-deploy otomatis oleh Hostinger ke `public_html` milik website academy.detaexpert.com, tampil di https://academy.detaexpert.com
- Cabang `app`: versi aplikasi lengkap (Next.js, login Supabase, pembayaran Midtrans). Lihat README di cabang itu.

Website statis tidak butuh Node.js atau database. Progres murid tersimpan di browser masing-masing.
